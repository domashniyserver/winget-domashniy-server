1. ЧТО ТАКОЕ WINGET?
--------------------------------------------------------------------------------
Winget (Windows Package Manager) — это официальный консольный менеджер пакетов
от компании Microsoft, встроенный в современные версии Windows 10 и Windows 11.
Он позволяет устанавливать, обновлять и удалять проверенные программы одной
командой из официального репозитория Microsoft без необходимости вручную искать
установщики на сайтах и снимать галочки с рекламного ПО.


2. КАК ПРОВЕРИТЬ НАЛИЧИЕ WINGET И УСТАНОВИТЬ / ОБНОВИТЬ ЕГО?
--------------------------------------------------------------------------------
Откройте терминал Windows (PowerShell или Командную строку) и выполните:

    winget --version

Если в ответ вы увидите номер версии (например, v1.8.1911 или новее), значит
Winget готов к работе.

Если система сообщает, что команда «winget» не распознана, или установлена
устаревшая версия:
  1. Откройте приложение Microsoft Store в Windows 11.
  2. В поиске введите «Установщик приложений» (App Installer) от Microsoft Corporation.
  3. Нажмите кнопку «Установить» или «Обновить».
  4. Дождитесь завершения и перезапустите окно PowerShell.


3. СОСТАВ КОМПЛЕКТА И НАЗНАЧЕНИЕ ФАЙЛОВ
--------------------------------------------------------------------------------
В папке «winget-domashniy-server» находятся 5 файлов:

  1) install-basic.ps1 — Базовый набор программ для чистой системы:
     - 7-Zip (7zip.7zip) — архиватор
     - VLC Media Player (VideoLAN.VLC) — универсальный медиаплеер
     - Mozilla Firefox (Mozilla.Firefox) — веб-браузер
     - Bitwarden (Bitwarden.Bitwarden) — менеджер паролей

  2) install-work.ps1 — Набор программ для работы:
     - 7-Zip (7zip.7zip)
     - Mozilla Firefox (Mozilla.Firefox)
     - Bitwarden (Bitwarden.Bitwarden)
     - LibreOffice (TheDocumentFoundation.LibreOffice) — офисный пакет

  3) install-study.ps1 — Набор программ для учёбы и конспектов:
     - 7-Zip (7zip.7zip)
     - Mozilla Firefox (Mozilla.Firefox)
     - LibreOffice (TheDocumentFoundation.LibreOffice)
     - VLC Media Player (VideoLAN.VLC)
     - Obsidian (Obsidian.Obsidian) — база знаний и заметки в Markdown

  4) check-updates.ps1 — Проверка и обновление установленных программ:
     - Показывает список всех программ, для которых доступны свежие версии.
     - Не запускает обновление автоматически — спрашивает подтверждение у вас.

  5) README.txt — Данная инструкция.

ПРИМЕЧАНИЕ О ПРОВЕРКЕ ИДЕНТИФИКАТОРОВ:
Идентификаторы пакетов (7zip.7zip, VideoLAN.VLC, Mozilla.Firefox,
Bitwarden.Bitwarden, TheDocumentFoundation.LibreOffice, Obsidian.Obsidian)
являются стандартными идентификаторами официального репозитория winget.
Поскольку подготовка файлов выполнялась в изолированной среде без живого
доступа к утилите winget.exe, перед массовым применением на рабочих машинах
рекомендуется проверить актуальность пакетов командой `winget show --id <ID> --exact`.


4. КАК СОХРАНИТЬ ФАЙЛЫ И ОТКРЫТЬ POWERSHELL В ПАПКЕ СО СКРИПТАМИ
--------------------------------------------------------------------------------
  1. Распакуйте архив winget-domashniy-server.zip в удобное место, например:
     C:\Scripts\winget-domashniy-server
  2. Откройте эту папку в Проводнике Windows 11.
  3. Вариант А (простой): щёлкните правой кнопкой мыши по пустому месту внутри
     папки и выберите «Открыть в Терминале» (Open in Terminal).
  4. Вариант Б (с правами администратора — рекомендуемый):
     - Нажмите правой кнопкой мыши на меню «Пуск» -> «Терминал (Администратор)».
     - Перейдите в папку со скриптами командой:
       cd C:\Scripts\winget-domashniy-server


5. КАК ЗАПУСТИТЬ СКРИПТЫ (И КАК ОБОЙТИ ЗАПРЕТ ВЫПОЛНЕНИЯ БЕЗОПАСНО)
--------------------------------------------------------------------------------
Обычный запуск (если выполнение локальных скриптов уже разрешено):

    .\install-basic.ps1

Если Windows 11 блокирует запуск скрипта с ошибкой «Выполнение сценариев
отключено в этой системе» (ExecutionPolicy Restricted), используйте безопасный
запуск с временным разрешением ТОЛЬКО для одного текущего окна/процесса:

    powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\install-basic.ps1"

Аналогично для остальных скриптов:

    powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\install-work.ps1"
    powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\install-study.ps1"
    powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\check-updates.ps1"

ВАЖНО О БЕЗОПАСНОСТИ:
  - Параметр `-ExecutionPolicy Bypass` в приведённой выше команде действует
    ИСКЛЮЧИТЕЛЬНО для одного конкретного запуска и не меняет глобальные
    настройки безопасности Windows. После закрытия окна защита остаётся прежней.
  - НИКОГДА не используйте `Bypass` и не запускайте от имени администратора
    незнакомые скрипты, скачанные с непроверенных сайтов или полученные от
    неизвестных отправителей. Перед запуском всегда открывайте `.ps1` файл в
    Блокноте и проверяйте, какие команды он выполняет.


6. ПОЛЕЗНЫЕ КОМАНДЫ WINGET ДЛЯ САМОСТОЯТЕЛЬНОЙ РАБОТЫ
--------------------------------------------------------------------------------
Проверить версию Winget:
    winget --version

Найти программу в репозитории (например, 7-Zip):
    winget search 7zip

Посмотреть подробную информацию о пакете по его точному ID:
    winget show --id 7zip.7zip --exact

Показать список всех программ, установленных на компьютере:
    winget list

Проверить, для каких программ вышли обновления:
    winget upgrade

Обновить все поддерживаемые программы одной командой:
    winget upgrade --all


7. ЧТО ДЕЛАТЬ, ЕСЛИ УСТАНОВКА ПРОГРАММЫ ЗАВЕРШИЛАСЬ ОШИБКОЙ?
--------------------------------------------------------------------------------
Скрипты спроектированы так, что при сбое установки одной программы они не
останавливаются, а продолжают устанавливать остальные и выводят код ошибки в
итоговом отчёте. Если возникла ошибка:

  1. Проверьте подключение к интернету и доступность серверов Microsoft/GitHub.
  2. Убедитесь, что окно PowerShell запущено от имени Администратора.
  3. Закройте программу, если она уже запущена в фоне (например, браузер Firefox
     или архиватор 7-Zip во время обновления).
  4. Попробуйте выполнить установку проблемного пакета вручную, чтобы увидеть
     детальное сообщение Winget:
     winget install --id <ID_пакета> --exact --source winget
  5. Обновите кэш источников Winget командой:
     winget source update
